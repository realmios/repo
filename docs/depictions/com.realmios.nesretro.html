NES Retro

Phiên bản 0.3.13 · iOS 15+ · Roothide, Rootless

Trình chơi game NES cho iPhone. Chọn file .nes của bạn hoặc tải game đề xuất từ kho, chọn giao diện máy cầm tay dọc hoặc ngang rồi chơi ngay.

  • Giao diện máy cầm tay dọc và ngang, nhiều màu và họa tiết
  • Nút chữ thập hoặc cần tròn; vừa di chuyển vừa bắn được
  • Nút liên thanh ⚡A, ⚡B, tua nhanh, bộ lọc kẻ ô kiểu tivi cũ
  • Lưu trạng thái 4 ô cộng ô tự động, lưu tiến trình game
  • Hỗ trợ tay cầm Bluetooth
  • Game đề xuất và ảnh bìa được cập nhật từ kho, không cần cài lại app
